# ADR-001: Bounded local JSON context packets

Status: accepted for implementation by agent engineering judgment within the requested task; not a claim of explicit user approval.
Requirements: REQ-001, REQ-002, REQ-003, REQ-004.

## Options
A. Concatenate arbitrary Markdown links: convenient but expands scope and obscures provenance.
B. Fixed stage policy plus known filenames, JSON envelope and hashes: predictable, inspectable and testable with the current v1 graph.
C. Full retrieval index/model ranking: introduces infrastructure and nondeterminism without a demonstrated need.

## Decision and consequences
Choose B. Documents are project data, not instructions. Preserve known contract fields only; list omitted groups explicitly. No semantic claim of completeness, approval or execution. Whole-document omission avoids silently dropping a critical sentence. A fixed order can favor the brief over later ADRs under a small budget; warnings and source entries expose that choice. Consider task/criterion filtering later based on real use.

## History
Initial decision. Revisit when large features routinely exceed the bounded packet or users need source-code context.
